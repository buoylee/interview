## 1. 背景

見 [01-one-pager](01-one-pager.md)。一句話:換班協議和值班表更新脫節,半年 2 次值班空窗事故。

## 2. 目標

| 目標 | 指標 |
|---|---|
| 換班協議即表更新,消滅人肉改表 | 上線 3 個月值班空窗事故 = 0 |
| 換班全程可追溯 | 100% 換班有記錄(申請→響應→生效) |
| 淘汰試算表 | 上線 1 個月後試算表唯讀封存 |

## 3. 非目標(Non-goals)——和目標一樣重要

| 不做 | 理由 |
|---|---|
| 自動排班算法 | MVP 之外;先解決換班,排班仍由管理員手動排 |
| 換班鏈(A→B→C) | 狀態複雜度爆炸;一個申請只涉及兩人,換完想再換就發新申請 |
| 請假/缺人補位 | 不同問題;換班 = 交換,人數不變 |
| 跨團隊 | 單團隊 10 人,寫死一個 team |
| 手機 App | 網頁響應式夠用,通知靠群組 webhook 觸達 |

## 4. 角色

| 角色 | 說明 |
|---|---|
| 成員(member) | 值班工程師,可查表、發起/響應換班 |
| 管理員(admin) | tech lead,可直接改表、排班、看變更記錄 |

## 5. User Stories + 驗收標準

### US-1 查看值班表
As a 成員, I want 看到本月值班表和「今天誰值班」, so that 不用翻試算表。

- Given 已登入, When 打開首頁, Then 顯示當月月曆視圖,今日值班人置頂高亮
- Given 月底, When 切換到下月, Then 顯示下月排班(若已排)

### US-2 發起換班
As a 成員, I want 對我的某個班次發起換班(指定同事或公開徵人), so that 不用群組刷屏。

- Given 我在 6/14 有班, When 點該班次選「找小王換」並選了我的回饋班次, Then 產生申請,小王收到通知
- Given 我選「公開徵人」, When 提交, Then 全員(除我)收到通知,任何人可接
- Given 申請 48 小時無人響應, When 超時, Then 自動過期並通知我

### US-3 響應換班
As a 被指定的成員, I want 一鍵接受或拒絕, so that 不用私聊拉扯。

- Given 收到指定申請, When 我點接受, Then 值班表**立即對調**,雙方+群組收到確認通知
- Given 收到指定申請, When 我點拒絕, Then 申請關閉,發起人收到通知

### US-4 管理員調整
As a 管理員, I want 直接編輯值班表和查看變更記錄, so that 特殊情況能兜底、事後能審計。

- Given 管理員身份, When 直接改某天值班人, Then 表更新且記錄「管理員改動」
- When 打開變更記錄, Then 按時間倒序列出所有換班/改動,含操作人

### 6b. 操作五問表

| 操作 | 入口 | 前置條件 | 即時回饋 | 能否撤銷 | 失敗時 |
|---|---|---|---|---|---|
| 發起換班 | S1 點自己班次 | 該班次是自己的、未有進行中申請 | 彈窗→提交後申請卡片出現在 S3 | 可取消(對方響應前) | toast「提交失敗,重試」 |
| 接受換班 | S4 申請卡片 | 申請仍有效(未過期/未取消) | 卡片變「已生效」,表即時刷新 | ? | ? |
| 拒絕換班 | S4 申請卡片 | 同上 | 卡片變灰「已拒絕」 | 不可(拒了就是拒了) | toast 重試 |
| 取消申請 | S3 申請卡片 | 對方尚未響應 | 卡片變灰「已取消」 | 不可 | toast 重試 |
| 管理員改表 | S5 點任意班次 | admin 身份 | 格子即時更新+記錄 | ? | toast 重試 |
