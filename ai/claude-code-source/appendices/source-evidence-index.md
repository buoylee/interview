### 7.2 High-risk applicability audit

- **Permission precedence**：P1–P7停止在authorization decision；Sandbox是final Allow后的独立containment/launch boundary。
- **Transcript timing**：S2、T1、T6、T7明确区分live update、append dispatch与durable completion；UI fire-and-forget不能推广成同步fsync。
- **Compaction/recovery**：C/R rows只证明legal next projection与fresh invocation，不证明unobserved external effect truth，也不承诺perfect replay。
- **Background task delivery**：D5、G7、G8区分terminal registry fact、`notified` guard、queue enqueue、drain与later model turn；没有durable/exactly-once delivery guarantee。
- **Queue semantics**：M5、R3、G4、G6分别界定acceptance、snapshot/drain、attachment projection与model consumption；任一早期success都不能替代later boundary。
- **Prompt cache**：K1–K8只证明prefix construction、conditional request markers与usage accounting；compatible prefix不保证hit。
- **Worktree**：K5把actual creation与notice分开；提示文本不创建隔离，且inherited context可因parent变化变stale。
- **Fork mode**：K6/K8明确区分background-enabled async ownership与global-disable sync direct-return ownership。
